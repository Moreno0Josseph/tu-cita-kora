# tu-cita-kora :)

Sitio Web oficial del centro estético KORA.

# Objetivo
Mi proyecto buscar aumentar el alcance y accesibilidad a un centro de nutrición y estética ya existente. A través de una página web que permita llenar una ficha clínica con información del paciente, agendar citas y realizar pagos.

# Tecnologías implementadas
    
    1. frontend/ — Aplicación web
    React + Vite + JavaScript + HTML + CSS
    
    2. backend/ — API y lógica del negocio
    
    Python + FastAPI + SQLAlchemy
    
    3. mobile/ — Aplicación móvil
    
    React Native + Expo
    
    4. database/ — Modelo y lógica de datos
    
    PostgreSQL + SQL
    
    5. docs/ y pruebas
    
    Git + GitHub
